## Description

FNaF Redone is a fan-made Android port of Five Nights at Freddy's 1 built for handhelds. On a dual-screen device, you play in the office on the top screen and use the cameras on the bottom. It also supports single-screen devices, and a Windows version is available.

The port aims to preserve the original FNaF 1 gameplay, features, and difficulty while adding quality-of-life improvements and cosmetic extras. It runs locally using your own Steam files.

## Setup guide

Download and install the latest release from the GitHub repository. You need your own Steam copy of FNaF 1: the app imports the files locally, then runs offline. On a dual-screen device, the office is shown on the top screen and the cameras on the bottom; single-screen devices can use the optional single-screen mode.

## Features

- Controller and touch controls
- Remappable controller controls
- Achievements and challenges
- Earnable points for office plushies
- Custom animated title screen
- Companion dashboard for the second screen
- Adjustable controls and sensitivity
- Optional single-screen mode for single-screen devices

## Requirements

- An Android handheld (dual-screen for the two-screen layout, or single-screen)
- Your own Steam copy of FNaF 1, which the app imports locally and runs offline
