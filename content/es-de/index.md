## Description

ES-DE (EmulationStation Desktop Edition) 3.5.0 has been released with improved dual screen support for the AYN Thor. It is a frontend for emulators that lets you browse and launch your game library, and this release refines how the interface works across the handheld's two screens.

## Setup guide

Download and install the latest release of ES-DE on your AYN Thor, then launch it to start using the improved dual screen support.
