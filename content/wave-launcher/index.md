## Description

Wave Launcher is an Android-based interface built around the design of the XrossMediaBar (XMB/PS3). It supports personal game libraries, rich metadata scraping, trophy tracking, and controller-friendly multimedia playback. Wave Launcher is a frontend, not an emulator — install and configure the emulators you want to use separately.

## Setup guide

Download the latest APK from the [Releases page](https://github.com/WaveLauncher/WaveLauncher/releases/latest) and install it on your Android device. For future updates, open Settings → Software Update in the app. The updater can check for and install new Wave Launcher releases, while also helping you import supported software sources and install or update emulators via your own Obtainium JSON or the RJNY Emulation Pack.

## Features

- XMB-style navigation designed around gamepads and touch, with support for PlayStation, Xbox, Nintendo, and virtual controllers.
- On-Screen Controller for devices that do not have a physical controller.
- Organize platforms, collections, favorites, and recently played games, with per-platform and per-game emulator assignments.
- Connect multiple cards, storage mediums, and directories, with hot-swap support and external-storage autorun.inf support.
- Metadata scraping through SteamGridDB, ScreenScraper, RetroAchievements, Hasheous, Google Play, and Web Search, with multi-language support.
- RetroAchievements and Dusklight (TwilitRealm) achievement tracking.
- Controller-friendly video, music, and photo playback, with background music, coldboot sounds, and separate volume controls.
- Wallpaper styles, color customization, brightness controls, custom fonts, interface scaling, text sizing, status bar options, boot logos, and custom UI sounds.
- Dual-screen layouts with per-screen orientation, app placement, screen swapping, and docked mode.
- Android app discovery with clear separation between games, emulators, and apps.
- Encrypted FTPS file sharing and an HTTPS Wave Portal for managing supported launcher content from a browser (experimental).
- Quick first-run setup, custom paths, and existing-file detection.
- Version 1.0.3 adds a File Explorer and a Wave Store preview to Experimental Features for supporters.
- Optional Root and Shizuku access for advanced storage access.
- Folder controls for Photos, Music, Videos, and Books.
- Alphabetical and Most Played sorting for Favorites.
- Platform renaming and a Japanese MAME name list for scraping.
- Default [1.0] and Default [0.9] startup sounds.
- A Home shortcut to return directly to Games.
- The WipEout collection.
- Android launch support for PokéDaisy, Eden Duo, Lemon, and DroidDeck.

## Requirements

- An Android device.
- A physical controller (optional) — an On-Screen Controller is available for devices without one.
- Emulators installed and configured separately, as Wave Launcher is a frontend, not an emulator.
