## Description

Pixel Navigator is an Android map companion app for emulated games. It grew out of the author's earlier project Fanmake Pokémon Maps, which provided maps and player tracking for RPG Maker XP Pokémon fangames. Pixel Navigator extends the same concept to ROMs and other emulated games across multiple systems.

The app shows game maps on a second screen while you play, tracks the player's position, and includes extras like a BattleDex and quest tracking for supported titles. The supported game list is large and growing: dozens of GBA Pokémon ROM hacks (Pokémon Unbound, Emerald Rogue, Radical Red, Gaia, Glazed, Clover, Crown, Odyssey and more), Dragon Ball Z: The Legacy of Goku I/II and Buu's Fury, The Legend of Zelda: The Minish Cap, NES Zelda titles, Pokémon Crystal Awakening on GB/GBC, and Breath of Fire III/IV on PlayStation.

The app is in beta and the author actively asks for testing feedback — just play normally and report when maps break, don't line up correctly, or don't work as expected. Since ROM hacks change frequently (some update every couple of days), map compatibility can vary between ROM revisions.

Game data is not included — you need your own legally obtained ROMs. Pixel Navigator is an independent project, not affiliated with Nintendo, Sony, or any game or emulator developers.

## Project status

The author's SSD died, taking the original source code and signing key with it. Using Codex, the app was recovered from the copy installed on the AYN Thor: roughly 670MB of app data, 332 app-specific source files with their class names intact, and a rebuilt APK whose 33,042 bundled asset files match the original byte-for-byte. Development continues, though updates may be slower while the recovered project is cleaned up and rebuilt. The author is now backing up properly.

## Setup guide

1. Download the APK from the Releases page on GitHub and install it on the AYN Thor.
2. Open the app and pick a supported game from the built-in game list (the full list is in the repository README).
3. Play the game in your emulator as usual — the map and tracking appear on the second screen.
