## Reporting issues

If you run into a problem while using SteamOS, first search the issue list to see if it has already been reported, including closed issues. Some issues belong to other trackers, such as Steam for Linux, Dota 2, Counter-Strike: Global Offensive, Portal 2, Half-Life 1 engine (GoldSrc) games, and Source games. When creating a new issue, include a short descriptive title, a detailed description with any command-line output, steps to reproduce, and your system information. Steam can also generate a system report via Settings -> System -> Advanced -> System Report -> Create Report; mention your Steam ID in the issue so the corresponding report can be retrieved.
