## Description
DualScreen Launcher is an Android game launcher built for dual-screen handhelds such as the AYN Thor. It brings supported PC and Nintendo Switch games into one interface and applies tested configurations and custom dual-screen mods so gameplay can use both displays.

Supported titles include some PC games, Super Mario Odyssey, Minecraft, and a Switch library with per-game required-version indicators. Each game gets a custom second-screen companion where the bottom display shows maps, inventories and other interactive info.
