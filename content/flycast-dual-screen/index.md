## Description

Flycast Dual Screen is a fork of Flycast, a multiplatform Sega Dreamcast, Naomi, Naomi 2 and Atomiswave emulator. The fork adds a dual-screen mode for the AYN Thor: while gameplay is shown on the main screen, the Dreamcast VMU screen is displayed on the bottom/secondary screen. The current release is v2.7-dualscreen.1.

## Features

- Emulates Sega Dreamcast, Naomi, Naomi 2 and Atomiswave software.
- Displays the Dreamcast VMU screen on the device's bottom/secondary display.
- Dedicated dual-screen builds are distributed through the project's GitHub Releases page.

## Requirements

- A dual-screen device such as the AYN Thor, with a secondary/bottom screen.
- A Sega Dreamcast game that makes use of the VMU screen to see the VMU in action.

## Setup guide

- Download and install the [latest release](https://github.com/ItsRetroPup/flycast/releases/latest) (v2.7-dualscreen.1) on your device.
- Launch Flycast and load a Sega Dreamcast game.
- When the game uses the VMU, the VMU screen appears on the bottom/secondary display.
