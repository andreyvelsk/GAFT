## Description

Theme Hospital DS for Thor is an unofficial dual-screen adaptation of Theme Hospital for the AYN Thor, built on CorsixTH and CorsixTH-Android. Your hospital stays on the top screen while the bottom screen handles building, furnishing, staff and management. It adds touch gestures, controller support, expanded decoration tools and a redesigned interface for dual-screen play.

You must supply your own full PC copy of Theme Hospital — no original game data is included or downloaded by this project. The app walks you through importing its files once, and updates keep your data and saves.

## Features

- Dual-screen interface: hospital gameplay on the top screen, management controls on the bottom.
- Swipe between management pages, including Build, Furnish and Edit Rooms, with continuous page cycling.
- Enlarged dialogues, clearer text and improved use of the bottom screen.
- Refined hospital overview showing finances, reputation, patients, staff and treatment progress.
- Enlarged animated adviser and a more prominent hospital-opening clock.
- Optional trackpad controls on a dedicated Controls page.
- Video cutscenes routed to the top screen.
- Touch controls: tap to select, pinch to zoom, two-finger pan, long-press to edit, and rotate objects while placing.
- Controller support for navigation, selection, placement and camera control.
- Decorating: recolour supported furniture and wall surfaces, choose floor and wall textures, paint individual sections, a whole wall run or a whole room.
- Optional vending-machine appearance packs selectable through the furnishing interface.
- Separate music and sound-effects volume controls and classic/remastered soundtrack selection when a compatible music pack is installed.
- Support for additional ambient receptionist announcements and optional startup artwork.

## Requirements

- AYN Thor is the primary target device.
- ARM64 Android device running Android 8.1 or later.
- Your own installed full PC version of Theme Hospital.
- English game-language data for the current importer.
- Enough free storage for the game files and a temporary import copy.

## Setup guide

1. Download the APK from the repository's Releases section.
2. Install it on your Thor. Android may ask you to allow installation from your browser or file manager.
3. Start the app.
4. Follow the game-data import instructions.
5. After a successful import, select Play Theme Hospital.

On your computer, locate the installed game folder (often called HOSP) containing the DATA, QDATA, LEVELS, SOUND and ANIMS folders. Copy that folder to your Thor, or compress it into a normal ZIP and transfer the ZIP. The importer accepts a ZIP with an enclosing installation folder and handles upper- or lowercase filenames.

Choose either "Choose installed game folder" or "Choose game-data ZIP". An installer EXE, disc image, save file or demo alone is not sufficient — install the full game on your computer first, then supply its installed data.

Imports are checked before replacing existing game data. After a successful import, the selected source folder or ZIP can be removed: the app keeps its own copy.

To update, install updates over the existing app — do not uninstall first. Official updates using the same package ID and signing certificate retain imported game data, saved hospitals, settings and previously installed optional enhancement assets.
