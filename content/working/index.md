## Description

Something the author and their brother are building for themselves, this project puts the AYN Thor's bottom screen to work under official SteamOS. Pressing the AYN button opens a performance dashboard, with toggles currently in development. A home screen lists apps, and Firefox is already working. The project was built for fun using Claude.

## Features

Performance dashboard opened from the AYN button, with toggles still in progress. Home screen with apps — Firefox is currently working.
