## Description

PPSSPP Duo is a fork of PPSSPP, the PSP emulator by Henrik Rydgård and the PPSSPP team. All the emulation is theirs; Duo adds the second screen. It installs as a separate app (org.ppsspp.ppssppduo) next to regular PPSSPP, so it doesn't replace it. The game stays on the main screen while the second screen shows a mod: quick actions, a gamepad, or a companion made for the game you're playing. It doesn't affect performance. No games are included — bring your own legally purchased games (dumped from your own UMDs or bought digitally).

## Features

A dashboard shows the game icon and title, FPS and speed, clock and battery, plus save/load state with a slot picker, fast forward, alternative speed, rewind, pause menu, pause, screenshot and mute. A gamepad provides every PSP button and the analog stick with multi-touch. A screen-off mode shows a black screen with the tabs hidden to save power, and a diagnostics tab exposes emulator status, display info and a memory view. Switch mods with the tabs at the top of the second screen; the choice is remembered per game. The gear tab holds the settings (default mod, haptics, which display to use).

## Games with dual-screen mods

When one of these games starts, its mod opens on the second screen by itself: Patapon gets big PATA / PON / CHAKA / DON drum pads and a song book that lights up as you drum; Grand Theft Auto: Liberty City Stories gets a full city map with your position and heading, the route you drove, mission targets and destinations; Lumines: Puzzle Fusion gets a big preview of the next blocks, score, high score, squares deleted, time and board fullness; Gran Turismo gets a telemetry view with speedometer, tachometer with the car's red line, gear, throttle and brake, and a track map that draws itself as you drive. Other releases of these games are recognized too, and the mods look up game data at runtime rather than relying on fixed addresses, but only the listed versions have been tested.

## Setup guide

Download the APK from the latest release and install it — it doesn't replace regular PPSSPP. Start a game: the second screen turns on by itself on dual-screen devices, while on a single-screen phone the app works like plain PPSSPP. The second screen can be turned off in Settings → System → Use second screen, or with the button at the bottom of its own settings page.
