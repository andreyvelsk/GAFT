## Description
DW2003 Dual Screen runs the PAL version of Digimon World 2003 (`SLES-03936`) through PCSX-ReARMed on Android and shows a live companion pane on a second display — the AYN Thor's second screen, a Galaxy Z Fold (hinge or split), or a tablet.

The companion reads the emulated RAM and updates in real time while you play:

- **Exploration** — current area, story stage, walkthrough hint, regional radar, Tamer level and Bits
- **Battle** — party HP / MP / EXP, party reordering, unlocked digivolutions
- **Management** — stats, elemental resists, skills and equipment
- **Flawe MOD Fast Travel** — a list of visited map icons

Other features include a Spanish / English panel, a virtual pad, physical controller support, Memory Card import/export, default and optional GameShark cheats, and in-app updates from GitHub Releases.

**The APK does not include a ROM, BIOS, or Flawe's patch** — you need your own legal copy of the game. Combined with Flawe's Mod 2.0 it's the best match for travel plus an in-game walkthrough.

The companion is built on top of markisha64's decompilation project for DW3/2003.
