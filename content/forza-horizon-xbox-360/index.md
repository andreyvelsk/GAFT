## Description

Forza Horizon (2012, Xbox 360) is an unofficial recompilation port: the game's PowerPC program is statically recompiled to C++ with ReXGlue. On the AYN Thor it runs close to 60 fps with some graphical compromises and a solid 30 fps with base settings. Performance is great on 8 Gen 2 devices.

## Features

- Android preview build.
- Native Vulkan renderer that draws the game directly, with an experimental option for up to 60 fps where the hardware is fast enough.

## Requirements

- AYN Thor handheld (Android).
- Your own legally obtained copy of Forza Horizon (Xbox 360); the project does not include any game data.

## Setup guide

Download and install the latest release of the Android preview on your AYN Thor.
