Gameplay is a free, open-source fork of [GameNative](https://github.com/utkarshdalal/GameNative). On the AYN Thor, the lower display shows the selected game's card while you browse. During a Windows game, you can open a touchpad on the lower screen to move the pointer on the upper one.

## Setup guide

1. Download and install **Gameplay-modern-release.apk** from [Gameplay releases](https://github.com/intercontinentalmassacre/Gameplay/releases/latest).
2. For a first game, open **System → itch.io Store** and search for a free title with a supported HTML5 build. Install it, open its card and choose **Play**.
3. For Windows games, connect a supported store or use **Add game** to import a local executable. Allow extra storage for the Windows runtime on first use.

## Tips

- Use the shoulder buttons to switch itch.io store categories. The lower screen shows artwork for the selected title.
- Supported PICO-8 and Game Boy games can use the Thor's physical controls.

## Compatibility

Windows game compatibility varies by title. The project's [compatibility notes](https://github.com/intercontinentalmassacre/Gameplay/blob/working-builds/docs/game-compatibility.md) list tested settings for individual games.
