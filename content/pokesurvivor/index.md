## Description

PokéSurvivor is a free fan game — a bullet-heaven in the style of Vampire Survivors that uses Pokémon Mystery Dungeon sprites. It has a roguelike layer, 966 Pokémon from the 9 generations, shinies and region-based gacha, with music and sound effects composed for the game. The game itself is made by JPTER78; this Thor build wraps it into an APK and adds controller support.

On Android the game was touch-only, and in the browser only the d-pad worked on the Thor. This build adds proper stick controls:
- Left stick moves (analog)
- ABXY picks your moves
- L1/R1 cycles them
- Start pauses
- Menus can be navigated with the stick

The game runs fullscreen, works offline and shows up in the Game Assistant as a game.

## Setup guide

Download and install the latest release APK on your Thor, then launch the game. It runs fullscreen and appears in the Game Assistant as a game. Use the left stick to move, ABXY to pick moves, L1/R1 to cycle them and Start to pause.

- Full analog stick movement
