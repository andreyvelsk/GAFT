## Description

Giraffic is a comic reader for Android that opens PDF, CBZ and CBR files. It was built with native controller support and dual screen support, because other readers on the market do not handle either properly. The app is designed for snappy button-based scrolling and for keeping fingerprints off the screen.

Giraffic is a paid app at $0.89/£0.79 with no ads, in-app purchases or tracking.

## Features

- Reads PDF, CBZ and CBR comic files
- Native controller support
- Dual screen support
- Snappy button-based scrolling
- No ads, in-app purchases or tracking

## Setup guide

Download and install Giraffic from the Google Play Store. Open the app and load a PDF, CBZ or CBR comic file to start reading. Connect a controller to use button-based scrolling.
