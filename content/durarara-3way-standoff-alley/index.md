## Description

Durarara!! 3way standoff -alley- is a visual novel set during the events of the anime, in which you play as your own character. For the most part it plays as a visual novel, but it also includes a pixel art navigator that lets you walk around the game's maps. You can take sides with different characters, and the game features a loose Persona-style social link system. This release provides a complete English translation of the game.
