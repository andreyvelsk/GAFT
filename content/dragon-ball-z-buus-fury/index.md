## Description

Dragon Ball Z: Legacy Trilogy is a dual-screen Android launcher made specifically for the AYN Thor. It combines three Game Boy Advance Dragon Ball Z games — Dragon Ball Z: The Legacy of Goku, Dragon Ball Z: The Legacy of Goku II, and Dragon Ball Z: Buu's Fury — into a single launcher with dual-screen presentation, custom lower-screen menus and interfaces, widescreen / adaptive-view support, a BIOS import prompt, individual ROM import for each game, and automatic resource preparation and extraction. Stable builds are available for all three games.

## Features

- Custom trilogy launcher
- BIOS import prompt
- Individual ROM import for each game
- Dual-screen presentation
- Widescreen / adaptive-view support
- Custom lower-screen menus and interfaces
- Automatic resource preparation / extraction
- Stable builds for all 3 games
- RetroAchievements support in The Legacy of Goku I

## Supported games

- Dragon Ball Z: The Legacy of Goku — European multi-language ROM
- Dragon Ball Z: The Legacy of Goku II — European multi-language ROM
- Dragon Ball Z: Buu's Fury — English USA GoodTools ROM and tested Spanish modded ROM
- Buu's Fury is not multi-language in the same way as the European ROMs for Legacy of Goku I and II

## Setup guide

- Download and install the [latest release](https://github.com/erpiopio/BuusFury-Thor/releases/latest) of the Legacy Trilogy for AYN Thor.
- Launch the application.
- If the BIOS is missing, the app asks for it at startup — import your own GBA BIOS.
- Import each game's ROM individually.
- No BIOS or ROMs are included; bring your own files.
