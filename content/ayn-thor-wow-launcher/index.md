## Description

The AYN Thor WoW Launcher plays all versions of World of Warcraft — Classic, Retail, and Forever — on the AYN Thor handheld. It adds a bottom-screen control pad with remappable buttons, a keyboard, and a trackpad, and is built on top of the WoW Forever for Android launcher by Jaredgei. The game runs natively on the device's CPU using Blizzard's Windows ARM64 client, so nothing is emulated as x86.

## Features

- Supports Classic, Retail, and Forever versions of World of Warcraft; all versions are included in the Data folder and .build.info file.
- Bottom screen acts as extra buttons, keyboard, and trackpad, mimicking an MMO mouse.
- All bottom-screen buttons are remappable and use the game's default keybinds for interface menus by default.
- Clicking R3 toggles between mouse and camera control; in mouse control mode, A and B act as left and right click respectively.
- The button pad acts as extra inputs only, so there is no ban risk.
- Many customizable settings for the button pad.
- Second-screen support can be disabled from the main launcher, so it works on other devices with the Snapdragon 8 Gen 2.
- Everything is WoW themed.

## Requirements

- AYN Thor (Snapdragon 8 Gen 2 / Adreno 740) or another Snapdragon 8 series device.
- Android 10 or newer, 64-bit.
- About 80 GB of free space for the game data (internal storage or SD card), plus about 4 GB of internal storage for the app and its Windows environment.
- A Mac or PC with the WoW version you want to play (Classic, Retail, or Forever) installed through Battle.net, to copy the game data from.

## Setup guide

- Download and install the latest release of the launcher from the [GitHub releases page](https://github.com/wyattabuntjer/AYN-Thor-WoW-Launcher/releases/latest).
- On your PC, make sure the WoW version you want to play (Classic, Retail, or Forever) is installed through Battle.net.
- Copy the Data folder and the .build.info file from your PC's WoW install into a folder on the Thor (the default is /storage/emulated/0/WoW Forever/).
- Open the launcher. Once your game files are configured, the app launches straight into the game.
