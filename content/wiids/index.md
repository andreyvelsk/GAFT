## Description

WiiDS is a project for the AYN Thor that brings Wii games to the handheld with full use of both screens. Making the bottom screen useful was a major focus — it isn't just something to look at every now and then. v1.0 ships with 7 games (including mods), with more to come. Note that Super Mario Galaxy looks slightly different than the pictures in the post — check the GitHub for the current look.

## Features

- Makes full use of the AYN Thor's two screens, with the bottom screen serving a real purpose
- Ships with 7 games (including mods) in v1.0
- More games planned for future releases

## Supported games

- 7 games (including mods) included with v1.0
- Super Mario Galaxy is among them — it looks slightly different than the pictures in the post (check the GitHub for details)
- More games planned for upcoming releases
