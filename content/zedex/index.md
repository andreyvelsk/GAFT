## Description
Zedex is a ZX Spectrum that behaves like a modern console. Save at any moment, put the picture through the CRT you remember, pick up a controller and play. It runs on Android 11 and later, with unmodified [Fuse](http://fuse-emulator.sourceforge.net/) as the emulation core and a native front end.

### Dual screen
On a dual-screen handheld — an AYN Thor and its like — the controls, the menu and the indicators move to the second panel entirely, leaving the first screen showing nothing but the machine. The setting cannot be switched on with no panel to move to, and unplugging one brings everything back.

With the library on, the panel shows whichever game is selected — its artwork, the facts and the description — and the list gets the whole first screen. Once a game is running, a corner switch flips the panel between the controls and that same page.

## Features
- **Save states** — a grid of cards, each showing the screen it holds; quick save and quick load on the shoulder buttons (Select + R1 / Select + L1)
- **Shaders** — scanlines, a CRT with curvature and glow, RGB/composite/RF signal, a black-and-white television
- **Controllers** — plug one in and it works, with RetroArch-style hotkeys
- **Profiles** — the joystick as any of the Spectrum's seven interfaces, plus editable key profiles
- **Touch** — a thumb pad, four drawn keyboards and a Kempston mouse mode
- **Cheats** — built-in pokes for 3,682 games, matched by file fingerprint
- **Capture** — screenshots as PNG, recordings to GIF or MP4
- **Machines** — Sinclair 16K–+3e, Timex, Pentagon, Scorpion and Spectrum SE
