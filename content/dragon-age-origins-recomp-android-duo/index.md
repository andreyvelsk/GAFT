## Description

Dragon Age: Origins Recomp Android Duo is a recompilation of the Xbox 360 version of Dragon Age: Origins into a native Android program, built and tested on the AYN Thor. It is based on the Dragon Age: Origins - Recompiled project. The app adds second-screen functionality for the Thor's dual displays, which may also work on other dual-screen devices, and includes an on-screen controller overlay for trying the game on a phone. The game has not been played through to completion, so bugs are expected; the parts that have been played perform very well, at 30+ fps before frame generation, with sections up to 50 fps when playing on FSR Balanced with Lossless x2.

## Features

- Second screen functionality for the AYN Thor's dual displays (tested only on the Thor; may work on other dual-screen devices)
- FSR 3.1 upscaling
- FSR 3.1 frame generation
- Lossless frame generation through LSFG-VK (the user provides their own Lossless.dll)
- 30/45/60/120 fps caps
- A converter for PC mods
- An on-screen controller overlay for trying the game on a phone
- A debug option in the launcher that creates a copy of the save on next boot and logs everything until the app closes, zipped into the download folder for bug reports

## Requirements

- The disc image of Dragon Age: Origins for Xbox 360 (title ID 454108C0): the English, Italian and Spanish edition (media ID 186A1115), which is also disc 1 of the Ultimate Edition
- Disc 2 of the Ultimate Edition for Xbox 360
- Title Update 7 (optional, but recommended)
- Lossless.dll (optional)

## Setup guide

Download and install the latest release of Dragon Age: Origins Recomp Android Duo. The first time you launch the game it takes files from the disc and builds the code to run on Android; this takes about 10 minutes on an AYN Thor.
