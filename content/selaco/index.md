## Description

Selaco is an Android port built for the AYN Thor handheld. The port adds dual-screen support, taking advantage of the device's two displays. The showcase image shows the game running on the handheld.

## Setup guide

Download and install the latest release of the port on your AYN Thor, then launch the game from your library.
