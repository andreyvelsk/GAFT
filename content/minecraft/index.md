## Features
- Full HUD on bottom screen including absorption hearts, heart effects, hunger, armor, breathing, off-hand slot, touch to select item, mini map, etc.

- Useable chat on the bottom screen either with a built-in keyboard or android keyboard (toggleable in settings)

- Customizable background textures (mossy cobble, bricks, dirt, stone, etc.).

- Touch screen inventory and block entity interaction including enchantment tables, anvils, beacons, chests, looms, grindstones, etc.

- Ability to bind extra keybinds to the Input tab (for extra keybinds for modded)

- Ability to individually enable and disable HUD elements on the bottom screen in the settings

- Creative Mode menus (though they are currently a little buggy but useable).
