## Description

SteamOS Installer for AYN Thor is an Android APK that installs and boots to SteamOS directly from the handheld. It targets the latest build of pb-os, the dual screen fork of the official SteamOS for ARM. The process removes the usual barriers to entry: no manually downloading files from GitHub, no flashing an SD card from a PC, and no changing ABL files. The app is currently in Early Access. A setup video shows the process start to finish from a stock Android Thor running the stock bootloader, taking around 14 minutes from downloading to booting into SteamOS.

## Features

- Installs and boots to SteamOS (pb-os) entirely from the handheld
- No manual file downloads from GitHub
- No SD card flashing from a PC
- No ABL file changes
- Based on the latest build of pb-os, the dual screen fork of the official SteamOS for ARM
- Simple, straightforward process designed to remove the barrier to entry

## Requirements

- AYN Thor (also tested on Retroid Pocket 6, Retroid Pocket Nova, and KONKR Pocket Fit)
- Snapdragon 8 Gen 2 or Gen 3 device
- Stock Android with the stock bootloader

## Setup guide

Download and install the Android APK on your Thor. The setup video demonstrates the process start to finish from a stock Android Thor running the stock bootloader; the whole flow takes around 14 minutes from downloading the APK to booting into SteamOS.
