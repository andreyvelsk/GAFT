## Description

Dragon Ball Z: The Legacy of Goku II is a native Android port of the GBA game, optimized for the AYN Thor Max. The top screen runs the game in widescreen, while the bottom screen provides a fully interactive touchscreen interface. The project uses native GBA recompilation and builds on the original work by Matthew Stanley. It currently supports the European ALFP ROM, including Spanish.

## Features

- Widescreen gameplay on the top screen
- Fully interactive touchscreen interface on the bottom screen
- Character stats
- Inventory and usable items
- Skills and abilities
- Quest journal
- Scouter map

## Requirements

- AYN Thor Max (or compatible Android device)
- A compatible game ROM (European ALFP, including Spanish)
- A GBA BIOS
- Neither the ROM nor the BIOS is included with the project

## Setup guide

- Download and install the latest release APK from the releases page.
- Provide your own compatible game ROM and GBA BIOS.
- Launch the app and play with the game on the top screen and the touch interface on the bottom screen.
