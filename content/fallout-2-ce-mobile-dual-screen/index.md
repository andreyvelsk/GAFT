## Description

This is an unofficial, fan-made fork of Fallout 2: Community Engine rebuilt for Android phones and dual-screen handhelds like the AYN Thor. It is not affiliated with or endorsed by Bethesda Softworks, ZeniMax Media or Interplay, and it contains no game data — you need your own copy of Fallout 2.

On a two-screen device the game world gets the whole top screen, while the bottom screen works as a live console: the HUD, a live automap that follows you, and the inventory, character sheet, Pip-Boy and map open down there while the world waits up top. Dialogue and barter also use the bottom screen, with large numbered options. The bottom screen offers several layout options (Classic, Map first, Two columns) and three ways to switch between screens (Rail, Slim rail, Top bar).

Controls are touch-first: tap to move and act, long-press for action menus, and drag and drop in the inventory. The game is currently an early beta, built on top of the Fallout 2 Community Engine.

## Features

- Touch UI replacing the game's screens (dialogue, barter, inventory, loot, character and level-up, character creation, Pip-Boy, automap, world map and town maps, skills, settings, save/load, main menu, called shots): tap to act, long press for the action menu, drag to move items, two fingers to zoom the map.
- HUD with buttons anchored to the screen's edges, attack modes with reload, the message log, and end turn/combat controls.
- Tactical view in combat (toggleable in settings): figures turn see-through, reachable hexes and every character's hex are drawn on the ground.
- Bottom-screen companion on dual-screen devices: the HUD, a live map, and the game's screens open on the bottom display with layout options (Classic, Map first, Two columns) and screen navigation (Rail, Slim rail, Top bar); dialogue and barter can be split across both screens.
- Saves: a list sorted by when saves were made, quick saves that never overwrite manual ones, a "Continue" entry in the main menu, restoration of interrupted saves, and optional marks for saves made with other game files or mods.
- Game files are imported from a folder or any archive (.zip, .7z, .rar, .tar...) copied from a computer, with RPU and other mods and saves; save export and import; "Replace game" for new builds and mod updates.
- Built-in mod features where mods can't run on CE: Inventory Filter's filters and party tabs in loot and barter.

## Requirements

- Android 7.0 or newer, arm64.
- A legal copy of Fallout 2 (available on GOG, Steam or Epic Games) — the app contains no game data.
- The dual-screen companion is made for the AYN Thor; the port also runs on phones (tested on a Redmi 15C, Android 16).
- Landscape orientation only.
- Recommended setup: Fallout 2 with the Restoration Project (RPU) 2.4.34 installed.

## Setup guide

- Download and install the latest APK (Fallout2-Dualscreen.apk) from the project's latest release.
- Copy your Fallout 2 folder from a computer to the phone: either as is or as a single archive (via cable, cloud drive or messenger). Mods installed there (for example RPU) and saves come along.
- Start the app and choose that folder or archive; the game files are imported automatically.
- Recommended: install the Restoration Project (RPU) into the game folder on a computer first, then copy the folder to the phone.
