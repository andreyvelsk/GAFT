## Description

Mahou Shoujo Madoka Magica Portable is a PSP game whose gameplay is a lot like Persona Q. This project provides a complete English translation of the game. The translation builds on abandoned work by Traduko Soft & Carlito, which was picked up, finished and polished to completion.

## Features

- Complete English translation of the full game
- Gameplay similar to Persona Q
- Finishes and polishes the existing translation work by Traduko Soft & Carlito

## Setup guide

Download the latest release of the English translation and apply it to your copy of Mahou Shoujo Madoka Magica Portable.

See the project page: [github.com](https://github.com/WarriorAmhar/MahouShoujo)
