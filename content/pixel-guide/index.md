## Description

Pixel Guide is a free app for the AYN Thor that was built to show guides, PDFs, maps, manuals and other useful material on the second screen while actually playing a game. It supports web content as well, and remains completely free with donations optional.

## Features

- Guides, PDFs, maps, manuals and other useful material on the second screen
- Web content support
- Completely free, with optional donations

## Setup guide

Download and install the latest release of Pixel Guide on your AYN Thor. Open the app on the second screen while playing a game to view guides, PDFs, maps, manuals or web content.
