## Description

Pixel Guide is a free app for the AYN Thor that shows guides, maps, manuals, PDFs and other useful material on the second screen while you play a game. It was built by a solo developer who wanted reference material available on the device's second display during gameplay, and it has grown into a widely used part of the Thor community thanks to user feedback and support.

## Features

Pixel Guide supports guides, PDFs, maps, manuals and web content, all viewable on the second screen while a game runs on the main display. The app is completely free, with donations optional, and that isn't changing. Users regularly keep it open on the second screen while playing, and many have shared their own setups running Pixel Guide.

## Setup guide

Pixel Guide is free to download and install on your Thor. Once installed, open it on the second screen while playing a game to keep guides, maps, manuals, PDFs or web content handy. Donations are optional and support the developer.

## Status

The developer is still around and wants to keep improving Pixel Guide when time allows. The app is working well and the developer is happy with where it is today, though further development has slowed recently. The developer is also interested in hearing how people use the app — which parts are used most and whether it stays open on the second screen during play.
