## Description

Pixel Guide is a free Android app for collecting and reading game reference material in one place. It was built as an Android alternative to the iOS-only Pocket Codex app and is designed and optimized for Android devices, including the AYN Thor's OLED screen. It lets you browse GameFAQs and Neoseeker guides, save complete HTML walkthroughs directly on your device, download manuals, import your own files, track RetroAchievements progress, and keep saved content available for local rendering.

Pixel Guide is not a fully offline app. An internet connection is required to browse online guide sources, find new guides, download guides, save web pages, download manuals, use Pixie AI, and open external shortcut URLs. Once guide content has been saved or imported, Pixel Guide can render that content locally on your device, including without a network connection. TXT guide translation also works without a connection after the required Google ML Kit language models have been downloaded.

The app is privacy-first: no telemetry, no tracking, and no background analytics. The only network call is a single proxy endpoint to IGDB for game search, hosted by Cloudflare.

## Features

- Browse and download guides directly from GameFAQs, including TXT and HTML walkthroughs
- Support for Neoseeker TXT guides and HTML walkthrough downloads, including multi-page guide saving
- Save complete single-file HTML guides directly on your device
- Built-in ad blocking while browsing supported web guides
- Add shortcut URLs for external guides, wikis, and custom resources
- Clean, distraction-free guide reader with Smart Text Formatting for classic TXT guides
- Table of Contents support and fast in-guide text search for TXT and HTML guides
- PDF fit-to-width reading
- Resume reading from where you last stopped
- Per-guide font size and font selection
- Theme-aware TXT and HTML guide display
- Controller navigation for readers, including page turning and scrolling
- Multi-window support for launching two Pixel Guide instances side by side
- Saved guide content can render locally without network access
- Download PDF manuals via ScreenScraper
- Download or import maps and charts
- Annotate image guides with text, shapes, and freehand doodles
- Library management: browse guides per game, manually add custom games, grid or list layout, custom artwork
- Game of the Month: discover the monthly retro game selected by the SBCGaming subreddit
- RetroAchievements: link your account, see progress, filter and sort achievements, and identify Missable, Progression, and Win Condition achievements
- Pixie AI: ask questions using Gemini AI with web search (requires your own Gemini API key; can be turned off)
- Supported file types: TXT, HTML, PDF, XLSX, CBZ, image-based maps and charts, imported local guides, and shortcut URLs
- Multiple reader themes, including OLED Black, Paperwhite, Matrix, Midnight, Plum, Dune Night, Dune Day, Cyberguide, Pumpkin, Velvet, Sage, Fuchsia, Harbor, and Rose
- Multi-language interface: English, Spanish, Portuguese, German, French, Italian, Turkish, and Polish
- On-device TXT guide translation powered by Google ML Kit, supporting 59 translation languages
- Supports Android 8.0 and newer, with a Universal APK option for broad device compatibility

## Setup guide

Download and install the latest release of Pixel Guide from GitHub Releases on your AYN Thor. The app supports Android 8.0 and newer, and a Universal APK option is available for broad device compatibility. Open the app on the second screen while playing a game to view guides, PDFs, maps, manuals or web content. Browse GameFAQs and Neoseeker guides, save walkthroughs, download manuals, or import your own files; saved and imported guide content can be read locally without a network connection.
